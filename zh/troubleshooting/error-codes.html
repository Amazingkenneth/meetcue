错误码参考 ​

MeetCue 的每条提示都带有一个错误码，例如 MC-AUD-001。在下面找到对应的错误码，查看含义与解决办法。应用里的“查看解决办法”按钮会直接打开本页对应的位置。

音频 ​

MC-AUD-001 ​

音频设备被其他程序独占 · 错误

解决办法: 在声音设置中打开该设备的属性，在“高级”选项卡里取消勾选“允许应用程序独占控制该设备”。

MC-AUD-002 ​

麦克风被禁止访问或已静音 · 错误

解决办法: 在系统隐私设置里允许桌面应用访问麦克风，并确认麦克风没有被静音（静音键、耳机开关或声音设置），然后重新开始拾取。

MC-AUD-003 ​

找不到可用的音频设备 · 错误

解决办法: 连接麦克风或扬声器，确认它们在声音设置中已启用，然后在 设置 › 音频 中重新选择。

MC-AUD-004 ​

音频设备已切换，采集已自动恢复 · 提示

解决办法: 无需操作。若电平条不再跳动，请在 设置 › 音频 中重新选择设备。

MC-AUD-005 ​

系统声音通道只收到静音 · 警告

解决办法: 确认会议声音从默认播放设备输出。测试时将扬声器静音或戴上耳机，避免麦克风代替环回通道录到声音。

MC-AUD-900 ​

此平台暂不支持音频采集 · 错误

解决办法: 当前版本只在 Windows 上支持音频采集。练习模式的“模拟延迟”方式仍可使用。

语音识别 ​

MC-ASR-001 ​

语音识别 API 密钥无效 · 错误

解决办法: 从供应商控制台重新复制密钥，粘贴到 设置 › 供应商与费用 中，然后点“验证”。

MC-ASR-002 ​

无法连接语音识别服务 · 错误

解决办法: 检查网络或代理设置，然后运行延迟探测，选择一个可以连通的端点。

MC-ASR-003 ​

语音识别服务限流 · 警告

解决办法: 稍等一分钟再试。如果反复出现，请到供应商控制台检查配额与余额。

MC-ASR-004 ​

语音识别服务返回了无法识别的响应 · 错误

解决办法: 将 MeetCue 升级到最新版本。若问题仍在，请导出诊断信息并提交 Issue。

MC-ASR-005 ​

尚未配置语音识别供应商 · 错误

解决办法: 在 设置 › 供应商与费用 中选择供应商并填写密钥，或者用演示模式在没有密钥的情况下体验。

大模型 ​

MC-LLM-001 ​

提示生成超时 · 警告

解决办法: 运行延迟探测，换用更快的模型或端点。下一个问题会照常生成提示。

MC-LLM-002 ​

大模型 API 密钥无效 · 错误

解决办法: 从供应商控制台重新复制密钥，粘贴到 设置 › 供应商与费用 中，然后点“验证”。

MC-LLM-003 ​

大模型服务限流 · 警告

解决办法: MeetCue 会自动重试。如果反复出现，请检查账户的速率限制与余额。

MC-LLM-004 ​

所选模型不可用 · 错误

解决办法: 在 设置 › 供应商与费用 中换一个模型。

MC-LLM-005 ​

大模型请求失败 · 错误

解决办法: 检查网络与供应商的服务状态页，然后重试。

MC-LLM-006 ​

无法解析模型的输出 · 警告

解决办法: 通常只是偶发。若经常出现，请为要点生成选择能力更强的模型。

快捷键 ​

MC-HK-001 ​

快捷键已被其他程序占用 · 警告

解决办法: 打开 设置 › 快捷键，为标红的项目换一个组合键。

系统 ​

MC-SYS-001 ​

缺少 WebView2 运行时 · 错误

解决办法: 从微软官网安装 Evergreen 版 WebView2 运行时，然后重新启动 MeetCue。

MC-SYS-002 ​

无法写入配置目录 · 警告

解决办法: MeetCue 已改为把设置保存在用户目录中。如需便携配置，请检查程序目录的写入权限。

MC-SYS-003 ​

系统凭据库不可用 · 错误

解决办法: API 密钥只保存在系统凭据库中。请确认凭据服务（凭据管理器、钥匙串或 Secret Service）正常运行后重试。

MC-SYS-004 ​

此平台暂不支持该功能 · 提示

解决办法: 该功能将在后续版本中支持，请查看文档中的平台支持表。

网络 ​

MC-NET-001 ​

无法建立安全连接 · 错误

解决办法: 如果所在网络使用 HTTPS 代理，请在 设置 › 供应商与费用 › 高级 中填写代理地址，并确认系统信任其证书。

预算 ​

MC-BUD-001 ​

预算已用 80% · 警告

解决办法: 花费已接近你设定的上限，如有需要可在 设置 › 供应商与费用 中调整预算。

MC-BUD-002 ​

预算已用完 · 警告

解决办法: MeetCue 已按你的设置处理。如需继续，请在 设置 › 供应商与费用 中提高预算。

练习 ​

MC-PRC-001 ​

无法读取练习文件 · 错误

解决办法: 请使用 .srt、.vtt、.txt、.md 或 .csv 文件，格式示例见“文件格式”参考页。

MC-PRC-002 ​

语音合成不可用 · 警告

解决办法: 在系统设置中安装对应语言的语音，或改为只在屏幕上显示问题进行练习。

诊断 ​

MC-DIAG-001 ​

诊断信息导出失败 · 错误

解决办法: 换一个有写入权限的文件夹（例如“文档”）后重试。

仍未解决？请导出诊断信息，并带上错误码提交 Issue。
