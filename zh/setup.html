首次设置 ​

本页介绍第一次启动 MeetCue 时打开的设置向导。整个过程约五分钟，大部分时间花在创建 API 密钥上。

开始之前 ​

你需要一个语音识别供应商账号和一个大模型供应商账号。MeetCue 不替你选：向导会把价格并排列出，由你决定。

任务本版本支持的供应商
语音识别Soniox、Deepgram
问题检测与要点生成Anthropic、Amazon Bedrock、任意 OpenAI 兼容接口

问题检测和要点生成可以用不同的模型，甚至不同的供应商。检测只需判断“是不是问题”，通常选便宜的模型就够了。

第 1 步：语言 ​

选择 English 或 简体中文，也可以跟随 Windows 显示语言。之后可在 设置 › 通用 中修改，所有窗口即时切换。

第 2 步：音频 ​

MeetCue 同时听两路声音：

  • 麦克风（我）：你说话用的麦克风。“系统默认”跟随 Windows 声音设置里选的设备。
  • 与会者声音：默认播放设备里播放的所有声音，会议软件就是从这里播放其他人的声音。

点击 测试电平，播放一段视频并说几句话，两个电平条都应跳动。如果系统声音一直没有电平，请看音频与设备。

建议戴耳机

使用外放时，麦克风也会录到与会者的声音。MeetCue 能过滤大部分回声，但戴耳机效果最好。

第 3 步：模型与价格 ​

为三项任务各选一个模型。表格列出每音频小时或每百万 token 的单价、每小时会议的预计费用，以及运行延迟探测后的实测延迟。

最省、最快、均衡 三个按钮只高亮建议，每一项都要你亲自点选确认；三项都选好后才能继续。

供应商接口列出、但 MeetCue 价格表里没有的模型标为 价格未知。点击 填写价格 可以手动输入，例如合同里的折扣价。

第 4 步：API 密钥 ​

为每个选中的供应商粘贴密钥，点击 保存并验证。密钥只保存在 Windows 凭据管理器中，不会出现在配置文件或日志里。

各家密钥的获取方法见供应商配置：

  • Soniox
  • Deepgram
  • Anthropic
  • Amazon Bedrock
  • OpenAI 兼容接口

验证失败时，提示里会带错误码，例如 MC-ASR-001。点击 查看解决办法 可直接打开对应说明。

第 5 步：延迟探测 ​

探测会测量从你的网络访问各供应商的速度，并为每家选出最快的端点。有密钥时花费几美分；只测网络则完全免费。可以先跳过，之后在 设置 › 供应商与费用 中运行。参见延迟探测。

第 6 步：完成 ​

下次会议开始时按 Ctrl+Alt+Space。想先看看效果，可以试试五分钟上手。
