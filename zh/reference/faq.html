常见问题 ​

常见问题的简短回答。遇到故障请从排错总览开始。

MeetCue 需要订阅吗？ ​

不需要。MeetCue 以 MIT 许可证免费开源。你用自己的密钥直接向语音和模型供应商按其正常价格付费。选择前设置里会显示每小时的预计费用，使用后会显示实际用量。

开一小时会要花多少钱？ ​

取决于你选的模型，差距可达数十倍。使用小模型的典型组合每小时几十美分，主要是语音识别费用。设置向导和 设置 › 供应商与费用 会按你的选择给出估算；也可以看价格参考。

其他与会者能看到 MeetCue 吗？ ​

默认情况下，屏幕共享和大多数录屏都看不到面板。部分录制方式和采集设备仍可能拍到，参见共享屏幕。MeetCue 不会加入会议，也不会向会议软件发送任何内容。

面试时使用 MeetCue 合适吗？ ​

这取决于你和具体场合。很多面试和考试不允许外部帮助，请遵守你认可的规则。练习模式就是为了让你在没有这些顾虑的情况下做准备。

支持哪些语言？ ​

界面支持英文和简体中文。识别和提示支持中文和英文，包括一句话里中英混说。其他语言在支持它们的供应商上也许可用，但没有经过测试。

能在 macOS 或 Linux 上用吗？ ​

两个平台都能编译，但本版本只在 Windows 上完成了音频采集、面板行为和安装包。

能用我自己电脑上运行的模型吗？ ​

可以，只要它提供支持流式输出的 OpenAI 兼容接口。在 OpenAI 兼容接口中填写它的 Base URL。语音识别仍需要使用支持的云服务之一。

为什么 MeetCue 需要麦克风？ ​

用于判断你何时开始、何时结束回答，在你说话时把新问题排队，并为已讲到的要点打勾。如果只需要提示，可以关闭 跟踪已讲要点。
