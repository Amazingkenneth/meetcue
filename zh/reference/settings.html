设置项 ​

本页列出所有设置项、在应用中的位置，以及它们在 settings.json 中的键名。通常在应用里修改即可；只有自动化部署或恢复时才需要手工编辑文件。

设置保存位置 ​

安装方式设置文件夹
Scoopscoop\persist\meetcue\config（升级后保留）
便携 zipMeetCue.exe 同级的 config
上述文件夹不可写时的回退位置%APPDATA%\MeetCue

文件夹中有 settings.json、latency-history.json、usage.jsonl、logs\ 和 practice\。设置 › 诊断 › 关于 会显示当前使用的文件夹。API 密钥不保存在这里，而是在 Windows 凭据管理器中。

如果 settings.json 无法读取，MeetCue 会把它重命名为 settings.json.bad 并以默认设置启动。

通用 ​

设置键名默认值
界面语言general.uiLanguage：system、en、zh-CNsystem
提示语言general.hintLanguage：followQuestion、en、zh-CNfollowQuestion
强调色general.accent#F5B841
登录系统时启动 MeetCuegeneral.autostartfalse
共享屏幕时隐藏面板overlay.hideInScreenSharetrue
鼠标穿透面板overlay.clickThroughfalse

面板最后的形态（overlay.mode：full、mini、hidden）和位置（overlay.x、overlay.y）会自动记住。

音频 ​

设置键名默认值
麦克风（我）audio.micDevice；留空表示系统默认空
与会者声音audio.remoteSource：allSystemSoundallSystemSound
会议语言audio.languages，例如 ["zh", "en"]["zh", "en"]
人声检测门限audio.vadThresholdDb，单位 dBFS-45
静音多久算一句结束audio.endpointSilenceMs700

供应商与费用 ​

设置键名
语音识别providers.asr
问题检测模型providers.detect
要点模型providers.hints
AWS 区域（Bedrock）providers.bedrockRegion
Base URL（OpenAI 兼容接口）providers.openaiBaseUrl
HTTPS 代理providers.proxy；留空表示使用系统代理
手动填写的价格providers.pricingOverrides
费用估算假设providers.estimate
预算providers.budget.sessionLimitUsd、monthlyLimitUsd、onLimit（notifyOnly、pauseHints、endSession）

asr、detect、hints 各自包含 provider、model 和 endpoint。端点为 {"mode": "auto"}（实测最快）或 {"mode": "host", "host": "<主机名>"}。
