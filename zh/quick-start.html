五分钟上手 ​

本页用一段录好的示例面试演示 MeetCue 的完整效果，让你在真实会议前先熟悉面板。不需要 API 密钥，也不需要麦克风。

启动演示 ​

  1. 如果 MeetCue 正在运行，先退出（右键托盘图标 › 退出 MeetCue）。

  2. 按 Win+R，输入下面的命令并回车：

    text
    MeetCue.exe --demo

    如果 Windows 找不到程序，请使用完整路径。通过 Scoop 安装时路径为 %USERPROFILE%\scoop\apps\meetcue\current\MeetCue.exe。

  3. 面板出现在屏幕右侧并带有 演示 标记，稍后自动开始回放。按 Ctrl+Alt+Space 可暂停和继续。

你会看到什么 ​

演示回放的是一场网络工程岗位的面试。注意面板的这几个部分：

  1. 问题卡片：面试官问完一个问题约一秒半后，出现一张卡片，灰色的是问题原文，下方是编号要点。
  2. 要点：每条要点由加粗的主词和几个灰色补充词组成。候选人讲到某条要点时，它会打上绿勾并变暗；下一条要讲的要点带 接下来 标签并高亮。
  3. 队列：面试官在第一个问题答完前又问了第二个问题时，新问题会排在顶部队列的 下一问，当前提示不会被替换。
  4. 底栏：最近一次提示的延迟。点击可打开延迟探测。

试试快捷键 ​

演示进行时试试下面的快捷键。即使焦点在其他程序上，它们也有效。

快捷键动作
Ctrl+Alt+Space开始 / 暂停拾取
Ctrl+Alt+H面板：完整 → 迷你条 → 隐藏
Ctrl+Alt+[ / Ctrl+Alt+]上一问 / 下一问
Ctrl+Alt+Enter把当前问题标为已答

下一步 ​

  • 在首次设置中配置供应商。
  • 阅读会议模式，了解问题如何被检测和排队。
  • 不用开会，通过麦克风在模拟面试中把整个流程试一遍。
  • 在练习模式中用自己的题目演练。
