# Job description: Network Security Engineer, AI Platform

A sample job description for MeetCue's practice mode. Add it under **Settings › Hints › Briefing material** before a mock interview, so hints refer to the role. The company and role are fictional.

## About the team

The AI Platform Security team protects the network and the machine learning systems behind our products: model training clusters, inference APIs, and an internal assistant built on large language models with retrieval over company documents.

## What you will do

- Design and run network security controls: zero trust access, segmentation, TLS everywhere, DNS and egress filtering.
- Build detections for intrusions and data exfiltration from flow logs, DNS, EDR and authentication data, including machine learning models.
- Lead incident response for network and cloud security events.
- Threat model and red team LLM applications: prompt injection, data leakage through retrieval, tool misuse, model supply chain.
- Advise product teams on using third-party AI APIs safely with customer data.

## What we look for

- 3+ years in network security, security engineering or a SOC.
- Strong grasp of TCP/IP, DNS, TLS, VPNs, firewalls and common attacks.
- Experience with a SIEM and writing detections; Python for automation and data analysis.
- Practical knowledge of machine learning for anomaly detection and how to evaluate it on imbalanced data.
- Familiarity with LLM security risks such as the OWASP Top 10 for LLM applications.

## Nice to have

- Cloud networking on AWS, Azure or GCP.
- Experience with Zeek, Suricata or similar network monitoring tools.
- Security certifications such as OSCP or GIAC, or published security research.

## Interview process

1. Recruiter call (30 minutes).
2. Technical round: network security, incident response and AI security scenarios (60 minutes).
3. Hands-on exercise: triage a set of alerts (90 minutes).
4. Behavioural round (45 minutes).
