# Job description: Backend Software Engineer

A sample job description for MeetCue's practice mode. Add it under **Settings › Hints › Briefing material** before a mock interview, so hints refer to the role. The company and role are fictional.

## About the team

The Commerce Platform team builds the services behind checkout, orders and inventory for an online marketplace with about 20 million monthly users. We run Go and Java services on Kubernetes, with PostgreSQL, Redis and Kafka.

## What you will do

- Design, build and operate backend services that handle thousands of requests per second.
- Improve latency and reliability: profiling, caching, query tuning, graceful degradation.
- Own services in production, including on-call, incident response and postmortems.
- Review code, write design documents and mentor newer engineers.

## What we look for

- 3+ years building backend systems in Go, Java, Python or a similar language.
- Solid fundamentals: data structures, algorithms, operating systems, networking.
- Experience designing APIs and distributed systems: idempotency, retries, queues, consistency trade-offs.
- Relational databases: schema design, indexes, transactions, reading query plans.
- Observability: metrics, logs, tracing, SLOs.
- Clear written and spoken communication.

## Nice to have

- Experience with Kafka or another event streaming system.
- Running services on Kubernetes and a public cloud.
- Using AI coding assistants responsibly in a team.

## Interview process

1. Recruiter call (30 minutes).
2. Technical round: fundamentals, one coding question and one system design question (60 minutes).
3. Behavioural round with the hiring manager (45 minutes).
