# 快捷键

本页列出 MeetCue 的全局快捷键并说明如何修改。焦点在会议软件上时这些快捷键同样有效。

## 默认快捷键

| 快捷键 | 动作 |
| --- | --- |
| `Ctrl+Alt+Space` | 开始 / 暂停拾取 |
| `Ctrl+Alt+H` | 面板：完整 → 迷你条 → 隐藏 |
| `Ctrl+Alt+[` | 上一问 |
| `Ctrl+Alt+]` | 下一问（练习中为跳过当前题） |
| `Ctrl+Alt+Enter` | 把当前问题标为已答 |
| `Ctrl+Alt+Shift` + 方向键 | 把面板向上、下、左、右移动 |
| `Ctrl+Alt+Shift+1`、`2`、`3` | 把面板移到保存的位置 1、2 或 3（该位置为空时：保存面板当前位置） |
| `Ctrl+Alt+Shift+P` | 隐藏面板 6 秒；再按一次立即回来 |
| `Ctrl+Alt+Shift+T` | 开启或关闭鼠标点击穿透面板 |

## 移动面板 {#move-the-panel}

把面板放在摄像头正下方，看提示时就像在看对方。按一下 `Ctrl+Alt+Shift` 加方向键，面板移动一小步；按住不放则持续移动。同时按住两个方向键可以斜着移动。面板不会移出屏幕，推过屏幕侧边时会移到相邻的屏幕，并记住你放下的位置。

## 保存的位置 {#saved-spots}

大多数会议里面板都有两三个合适的位置：共享屏幕旁边、摄像头下方，或者避开其他参会者视频的角落。每个位置保存一次，之后用快捷键来回切换：

1. 把面板放到不挡任何东西的地方。可以用面板上的 **移动** 贴靠到边缘或角落，也可以直接拖动。
2. 按 `Ctrl+Alt+Shift+1`。该位置为空时，快捷键会保存面板当前的位置、大小和形态（完整面板或迷你条）。
3. 之后再按 `Ctrl+Alt+Shift+1`，面板就会回到这里。

面板上的 **移动 › 已保存的位置** 和 **设置 › 通用 › 面板** 会列出这些位置，并可以改存或删除。

## 操作面板后面的内容

- `Ctrl+Alt+Shift+P` 把面板隐藏 6 秒，足够点击面板后面的 **加入会议** 或其他会议按钮，之后自动回来。
- `Ctrl+Alt+Shift+T` 开启鼠标点击穿透：面板变淡，鼠标直接作用于后面的窗口。再按一次快捷键，或在托盘菜单中点 **鼠标点击穿透面板**，面板即可恢复点击。

## 为什么选这些键

默认键位避开了 Windows 笔记本上常见的快捷键：

- 会议软件常用的 `Ctrl+Shift` 组合，例如 Teams 的静音；
- 输入法使用的 `Ctrl+Space` 或 `Shift+Space`；
- 显卡驱动用于旋转屏幕的 `Ctrl+Alt` 加方向键，所以移动面板的快捷键另加了 `Shift`；
- 聊天软件使用的 `Ctrl+Alt+A`、`Ctrl+Alt+W`、`Ctrl+Alt+Z`；
- 功能键，很多笔记本默认把它们当作媒体键。

## 修改快捷键

1. 打开 **设置 › 快捷键**。
2. 点击对应动作旁的 **修改**。
3. 按下新的组合键。按 `Esc` 取消。

如果该组合已被其他程序占用，这一行会标红并显示 [MC-HK-001](/zh/troubleshooting/error-codes#mc-hk-001)，请换一个组合。**恢复默认** 会还原上表的键位。

## 快捷键收不到的情况

前台窗口是以管理员身份运行的程序，或独占全屏的游戏时，Windows 不会把快捷键传给 MeetCue。参见[快捷键与悬浮窗](/zh/troubleshooting/panel)。
