# 会议模式

本页说明 MeetCue 如何跟随一场实时会议：什么时候出提示、连续几个问题如何处理，以及怎样看懂面板。

## 开始与暂停拾取

按 `Ctrl+Alt+Space`，或点击面板上的 **开始**。状态点变绿，计时开始。再按一次即暂停；暂停期间不会向任何供应商发送数据。

也可以在托盘图标菜单中开始或暂停。

## 从问题到提示

1. **识别**：两路音频实时发送给语音识别供应商。只发送含有语音的部分，静音会跳过（只保留很短的保活信号）。
2. **检测**：其他与会者说完一句话后，检测模型判断这是不是问给你的问题。你自己麦克风里的话永远不会被当作问题。
3. **提示**：对于问题，要点模型生成三到五条编号要点和一段简短的示例回答。要点边生成边逐条显示。

开启 **提前触发**（**设置 › 提示**）后，说话人一停顿，MeetCue 就开始生成，而不必等这句话正式结束。如果对方只是停顿后接着说，提示会按整句话重写；如果问题明显变了，提前发出的请求会被取消并重新生成。大多数问题因此能快几百毫秒。

说话人在问题中间停顿时（“你怎么看 A……还有 B？”），后半句会并入同一张问题卡片，提示会重写以同时覆盖两部分，而不是只回答前半句。参见[一个问题被切成两段](/zh/troubleshooting/quality#split)。

开启 **边判断问题边生成提示**（同在 **设置 › 提示**，默认开启）后，问题判断和提示生成同时开始，而不是先后进行。只有判断确认是问题时才会显示提示，面板上看不出区别，但第一条要点通常能早一秒左右出现。看起来像问题、实际不是的句子，会多花一次用不上的提示请求。

## 看懂面板

完整面板自上而下依次是：

1. **标题栏**：状态、已用时间、暂停、置顶，以及切换到迷你条。
2. **音源**：麦克风和系统声音各一个电平条。面板一显示电平条就会跳动，不必先开始，方便确认 MeetCue 能听到你。开始之前不会向任何供应商发送内容。
3. **问题队列**：上一问、当前、下一问及其状态。点击卡片即可滚动到对应问题。
4. **对话**：每个问题一个聊天块。正在回答的问题始终在最上方，其后是排队等待的问题，再往下是较早的问题（新的在前）。点击灰色问题原文可以看到前后几句转写以及识别依据。**查看全文** 展开示例回答。
5. **底栏**：快捷键提示和最近一次提示的延迟。

**迷你条**（`Ctrl+Alt+H`）只显示当前问题、进度、下一条要讲的要点（大字）以及排队的问题数。

为了让视线靠近摄像头，可以用 `Ctrl+Alt+Shift` 加方向键把面板移到摄像头正下方。参见[移动面板](/zh/guide/shortcuts#move-the-panel)。

## 让面板不挡事

面板不应挡住会议的 **加入** 按钮、其他参会者或共享的屏幕。以下操作都可以用触控板完成：

- **从任意位置拖动。** 按住面板的任意空白处（不只是标题栏）即可拖动。触控板上轻点两下再拖动同样可以移动。
- 标题栏中的 **移动** 提供一键操作：
  - **贴靠到边缘或角落**：八个方向箭头把面板放到屏幕对应的边缘，并避开任务栏。连接多个屏幕时，中间的按钮把面板移到下一个屏幕。
  - **已保存的位置**：最多保存三个位置，各自记住大小和形态，用 `Ctrl+Alt+Shift+1`、`2`、`3` 返回。参见[保存的位置](/zh/guide/shortcuts#saved-spots)。
  - **大小**：窄、标准或宽，高度为屏幕的三分之一、一半或全高。也可以直接拖动面板边缘，大小会被记住。
  - **不透明度** 和 **文字** 大小，让更小、半透明的面板依然清晰可读。
  - **隐藏 6 秒**（`Ctrl+Alt+Shift+P`），用来点击面板后面的东西。
  - **鼠标点击穿透**（`Ctrl+Alt+Shift+T`）：面板变淡，鼠标直接作用于后面的窗口。再按一次快捷键或使用托盘菜单即可关闭。

所有窗口的字体，以及面板的文字大小和不透明度，也可以在 **设置 › 通用** 中设置。

## 已讲要点打勾

开启 **跟踪已讲要点** 后，MeetCue 会把你说的话与要点对比。讲到的要点打上绿色对勾，下一条未讲的要点标为 **接下来**。你还在说话时要点就会打勾，不必等你停顿。如果某条要点勾错了或漏勾了，点击它即可打勾或取消，之后 MeetCue 会保持你的设置。英文按单词匹配（单复数和时态视为同一个词），中文按相邻两字匹配，所以换个说法讲到也能识别。

如果你用外放而不是耳机，麦克风也会录到其他与会者的声音。MeetCue 会忽略与刚刚播放内容高度相似的麦克风文字，避免别人的话把你的要点勾掉。

## 同时出现多个问题

- **插话自动排队**（默认开启）：你正在回答时被问到的新问题会排在 **下一问**。你答完之后，它自动成为当前问题。
- 你没有在说话时出现的新问题会替换当前问题，原问题移到 **上一问**。
- 用 `Ctrl+Alt+[` 和 `Ctrl+Alt+]` 在问题间切换，用 `Ctrl+Alt+Enter` 把当前问题标为已答。

只有在你开口回答并停下之后，问题才算已答；开口前的沉默不会让问题被提前归档。

## 共享屏幕时隐藏面板

**共享屏幕时隐藏面板** 默认开启。Teams、Zoom、浏览器屏幕共享和大多数录屏工具会拍到面板后面的内容，而不是面板本身。

::: warning 并非绝对
部分录制方式和外接采集设备仍可能拍到面板。依赖这项功能之前，请先用你的会议软件实际测试。
:::

## 会议中的费用

每次调用的用量都会记录，并按下载的价格表折算；没有价格的模型只计用量、不计费用。**设置 › 供应商与费用** 显示本月按供应商分列的用量。可以设置单次会议和每月预算：用到 80% 时提醒；到 100% 时按你的选择只提醒、暂停要点生成或结束会话。
