# 实机测试清单

本页列出只能在真实 Windows 电脑上完成的检查：音频、快捷键、面板、语音合成和真实供应商延迟。其余部分由自动化测试覆盖。每次发布前，用 `scoop install meetcue` 安装后逐项检查。

某项未通过时，记下错误码（如有），[导出诊断信息](/zh/troubleshooting/diagnostics)并[提交 Issue](https://github.com/Amazingkenneth/meetcue/issues/new?template=bug.yml)。

## 先运行自检

- [ ] `MeetCue.exe --version` 输出预期的版本号。
- [ ] 将扬声器静音或戴上耳机，运行 `MeetCue.exe --self-test`，所有项目都显示通过。

## 设置与演示

- [ ] 首次启动出现设置向导；填入语音识别和模型密钥后，延迟探测给出结果表和组合排名。
- [ ] `MeetCue.exe --demo` 能完整播放示例面试。

## 音频

- [ ] 播放视频时“系统声音”电平条跳动；对着麦克风说话时“麦克风”电平条跳动。
- [ ] 使用外放而不是耳机时，对方的话不会被当成你说的。
- [ ] 拔插耳机或切换默认设备后，采集自动恢复。

## 会议

- [ ] 真实会议中，对方问完问题约 1.5 秒内出现问题块和要点，底栏延迟数字与之相符。
- [ ] 回答时，讲到的要点打勾，下一条高亮。
- [ ] 你回答时对方插话提问，新问题进入 **下一问**，当前提示不被替换。
- [ ] 五个快捷键全部生效；会议软件自己的快捷键（如 Teams 的 `Ctrl+Shift+M`）仍然正常。
- [ ] 点击面板不会让会议窗口失去焦点。
- [ ] 共享整个屏幕时，对方看不到面板。

## 练习

- [ ] 托盘菜单的 **模拟面试…**、空闲面板上的 **试试模拟面试**、**设置 › 通用 › 打开模拟面试** 和设置向导中的 **完成并开始模拟面试** 都能打开模拟面试窗口。
- [ ] 每个内置示例都能用 **使用** 载入；至少按[自测方案](/zh/guide/mock-interview#self-test-plan)完成第 1 轮和第 3 轮。
- [ ] 用示例字幕和示例问题列表各练一轮。
- [ ] **问题语音转文字** 开启和关闭时都能出提示。
- [ ] 四档提示难度切换正常。
- [ ] 复盘报告可以导出。

## 语言与错误

- [ ] 在设置中切换 English / 简体中文，面板、托盘菜单、错误信息和练习报告即时切换。
- [ ] 故意填错一个密钥，错误提示带错误码；点击 **查看解决办法** 打开当前语言的文档并定位到该错误码。
- [ ] 诊断压缩包里没有任何密钥。

## 升级与文档

- [ ] 执行 `scoop update meetcue` 后，设置、密钥、延迟历史和练习记录都还在。
- [ ] 文档站点在手机和电脑上都便于阅读；切换语言后停留在对应页面；搜索中文关键词能找到结果。
