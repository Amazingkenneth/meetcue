# 隐私与数据

本页说明 MeetCue 会把什么发给哪家供应商、在你的电脑上保存什么，以及哪些数据永远不会收集。MeetCue 没有自己的服务器：一切都在你的电脑上运行，用你自己的密钥直接连接你选择的供应商。

## 发给语音识别供应商的内容

- 拾取开启期间，麦克风和系统声音的音频，转换为 16 kHz 单声道。静音部分不发送，但说话开始前约 0.3 秒会一并发送，以免截掉第一个字；说话结束后约一秒内的静音也会发送，以便识别服务判断一句话已经说完。
- 会前资料中的术语，作为识别热词。
- 练习模式关闭 **问题语音转文字** 时，不发送对方的音频。

## 发给大模型供应商的内容

- 问题检测：识别出的句子和前后几句上下文。
- 要点生成：问题、最近的对话、你的角色，以及会前资料的一小段摘录。
- 练习模式：题目、识别出的你的回答、用于反馈的参考回答，以及需要分类的字幕句子。
- 延迟探测：一小段内置的示例转写。

## 价格查询

为估算用量费用和预算，MeetCue 会在启动时读取 Anthropic、Soniox、Deepgram 的公开价格页，以及本站的[价格参考](/zh/reference/pricing)。这些只是普通的网页下载，不会发送任何密钥、账号或会议内容。

你发给各供应商的数据适用其各自的隐私政策和数据保留条款。在保密会议中使用 MeetCue 之前，请先查阅这些条款。

## 保存在你电脑上的内容

| 数据 | 位置 |
| --- | --- |
| API 密钥 | Windows 凭据管理器中名为 `MeetCue` 的条目 |
| 设置、角色和抽取的会前资料文字 | 设置文件夹中的 `settings.json` |
| 延迟探测结果 | `latency-history.json` |
| 每次调用的用量与费用（不含内容） | `usage.jsonl` |
| 日志，保留 7 天；除非开启调试日志，否则不含转写（最近的内容也显示在 **设置 › 诊断 › 运行日志** 中） | `logs\` |
| 最近一份价格表，供离线使用 | `pricing.json` |
| 练习报告 | `practice\` |

设置文件夹的位置见[设置项](/zh/reference/settings#where-settings-are-stored)。音频永远不会写入磁盘。

## MeetCue 不会做的事

- 不收集遥测、使用统计或崩溃报告。
- API 密钥不会传给界面，不会写入文件，也不会写进日志。
- 导出的诊断信息不包含密钥、转写、会前资料或练习记录。
- 拾取暂停期间不会向任何地方发送数据，你主动运行的延迟探测除外。

## 删除你的数据 {#delete-your-data}

**设置 › 通用 › 清除所有数据** 可以一步完成：输入确认词后，MeetCue 会从凭据管理器中移除它的 API 密钥，删除上表中设置文件夹里的所有内容，清空界面自身的浏览器存储，关闭开机自启，然后像刚安装时一样重新启动。

如果要彻底移除 MeetCue：

1. 用 `scoop uninstall meetcue --purge` 卸载，同时删除设置文件夹。
2. 在 **凭据管理器 › Windows 凭据** 中删除名为 `MeetCue` 的条目。

无论哪种方式，都请按各供应商的政策，请他们删除保留的数据。
