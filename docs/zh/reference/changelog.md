# 更新日志

MeetCue 的重要变更记录。版本号遵循[语义化版本](https://semver.org/lang/zh-CN/)。

## 未发布

### 新增

- 新增两个适合普通话会议的语音识别供应商：**阿里云（Fun-ASR）**，提供新加坡和北京两个地域；**腾讯云语音识别**，提供中英混合与方言模型。见[供应商配置](/zh/guide/providers#alibaba-cloud)。

## 0.3.3 — 2026-10-29

### 新增

- **知识库**：加入简历、项目笔记、演示文稿或表格，提示会基于你的真实经历。较长的文件会在本机按问题检索，每个问题只带上与之匹配的段落。新增支持 Excel、PowerPoint（含备注）、OpenDocument、RTF 和 HTML，并可一次添加多个文件。
- **试一个问题** 可查看某个问题会带上哪些知识库段落。
- **设置 › 提示 › 提示词** 显示提示模型的指令并可修改，缺少占位符时会提醒，也可一键恢复内置版本。

### 变更

- 说话人在问题中间停顿（“你怎么看 A……还有 B”）时仍算作一个问题：后半句并入同一张卡片，提示会重写以覆盖每个部分，而不是只回答前半句。提前触发在停顿处已经开始时同样如此。
- 能识别不像问句的请求，例如“谈谈你的看法”“Talk about…”“Share a time…”。
- 复合问题保留判断期间已生成的提示，第一条要点约早一次模型往返出现。
- 提示先给出直接回答，按顺序覆盖复合问题的每个部分，能理解识别错的词，示例回答更短、更适合直接说出口。
- 面板只完整显示当前问题，其他问题在下方各占一行。点击某一行即可查看该问题，**回到当前问题** 一键返回。
- 还没开口回答上一个问题时被问到的新问题，会直接成为当前问题，不再排在后面等待。

## 0.3.2 — 2026-10-29

- macOS 13 及以上版本支持原生麦克风与系统声音采集、权限指引、透明面板，以及 Apple 芯片和 Intel 的应用包/DMG 构建。
- 复用 macOS 朗读引擎，避免列出语音后导致后续试听和模拟面试无法朗读；设备故障或睡眠后可重新打开音频流。

## 0.3.0 — 2026-10-27

### 新增

- 模拟面试内置四套示例，两套英文、两套中文：软件工程师、网络安全与 AI、后端开发工程师（中文）和运营商网络运维（中文，42 道题，分七组）。
- **跳到某道题**：模拟面试中可随时向前或向后跳到任意一道题，练习窗口和面板练习栏都可以操作。
- 开始模拟面试前可批量修改：勾选多道题（按住 Shift 可选一段），移到最前或最后、只保留这些、设置分组或删除。列表可按文字或分组筛选，也可以添加自己的题目。
- Windows 没有英文或中文语音时，声音检查会提示，并提供打开相应 Windows 设置的按钮和图文步骤。
- 面板上的 **移动** 提供适合触控板的一键摆放：贴靠到任意边缘或角落（避开任务栏）、移到下一个屏幕、窄/标准/宽以及 ⅓、½ 或全高、不透明度、文字大小、隐藏 6 秒和鼠标点击穿透。
- **保存的位置**：最多保存三个面板位置，各自记住大小和形态，用 `Ctrl+Alt+Shift+1`、`2`、`3` 一键前往。位置为空时，快捷键会保存面板当前的位置。
- `Ctrl+Alt+Shift+P` 把面板隐藏 6 秒，方便点击后面的内容；`Ctrl+Alt+Shift+T` 和托盘菜单项可以开关鼠标点击穿透。
- **字体**（**设置 › 通用**）可以更改所有窗口的字体，面板的文字大小和不透明度也可以在这里设置。

### 修复

- 在触控板上轻点两下再拖动，或双击标题栏，会把面板放大到盖住整个屏幕。现在可以从面板任意空白处拖动，面板也不会再最大化。
- 拖动面板边缘设定的大小会被保留，不会在下次切换形态时被重置。
- 录制带 `Shift` 和数字的快捷键时，保存的是符号（`!`）而不是数字。

## 0.2.4 — 2026-10-27

### 新增

- **放大会议中轻声说话的人**（**设置 › 音频**，默认开启）会在识别前把说话轻的参会者提升到正常音量；系统声音也有了单独且更低的人声门限（−60 dBFS），轻声提出的问题不再被漏掉。
- **边判断问题边生成提示**（**设置 › 提示**，默认开启）让提示生成与问题判断同时开始，第一条要点通常能早一秒左右出现。
- 鼠标悬停在面板底栏的延迟上，可查看上一条提示在识别、判断和生成上各用了多久。提示偏慢时，面板会指出最慢的环节和最有效的设置。

### 修复

- 与设置文件夹无关的失败（例如窗口或文件对话框打不开）也会显示 `MC-SYS-002`（“无法写入配置目录”）。现在这类失败显示 `MC-SYS-006`，设置保存失败显示 `MC-SYS-005`。
- 登录或更新后不久，检查程序旁的设置文件夹能否写入时可能短暂失败，导致设置改存到 `%APPDATA%\MeetCue`。现在会重试，相关提示也只显示一次，而不是每次启动都显示。

## 0.2.3 — 2026-10-26

### 新增

- 模拟面试窗口改为四步引导：声音检查（含实时电平）、选题目、确认题目、开始练习。每一步都会写明下一步要做什么，练习过程中也会提示当前该做什么。
- 新增 **再问一遍**：从头重读当前这道题，练习窗口和面板上都有。
- 可以在声音检查这一步按语言选择朗读问题的语音，并点 **试听** 试听。朗读语速也移到了这里。

### 修复

- 问题有时读到一半就停：咳嗽、“嗯”，或者把问题本身的回声听错一个词，都会被当成用户开始回答。现在必须是真正的说话才会打断，练习设置里的口头禅一律不算。

## 0.2.2 — 2026-10-26

### 新增

- 模拟面试更容易找到：托盘菜单靠上位置新增 **模拟面试…**，空闲面板上有入口链接，也可以从 **设置 › 通用** 和设置向导最后一步打开。窗口最上方有分步的 **流程** 说明。
- 练习的播放方式改为 **问题语音转文字** 开关：开启（默认）时像会议一样把朗读的问题转成文字；关闭时问题文本直接交给要点模型。两种情况下问题都会朗读出来。**识别我的回答** 改名为 **我的回答语音转文字**。
- 内置软件工程和网络安全与 AI 方向的示例面试，包括问题列表和面试字幕，一键即可载入。可作为会前资料的示例职位描述放在 `samples/materials`。
- 新增[模拟面试指南](/zh/guide/mock-interview)，介绍如何不开会、通过麦克风把整个软件测一遍。

## 0.2.1 — 2026-10-26

### 修复

- 会议或练习一开始，面板和 **设置 › 音频** 里的电平条就不再跳动，看起来像 MeetCue 在听的时候麦克风没有声音。练习也因此察觉不到你开始说话。

## 0.2.0 — 2026-10-26

### 变更

- 设置向导和 **设置 › 供应商与费用** 使用同一套方式自由填写供应商和模型：为每项任务选择供应商并填写任意模型名。供应商返回的模型名会作为输入建议；MeetCue 不再列出模型和价格，改为链接到各供应商的官方价格页。
- Anthropic 可以经由网关或代理访问：在密钥旁填写接口地址即可。接口地址现在按供应商保存在 `providers.baseUrls` 中，原有的 OpenAI 兼容接口地址会保留。
- 用于预算统计的价格在 **设置 › 供应商与费用 › 预算 › 你填写的价格** 中填写。

### 修复

- 在 Windows 上点按钮打开 **重新运行设置向导**、运行日志或其他窗口时，MeetCue 会卡死：所有窗口都无法移动，程序也无法退出。
- 语音识别：
  - 会议开始时如果还没有任何声音播放，系统声音的识别约 20 秒后就会中断并显示 `MC-ASR-002`。现在无论是否有音频都会保持连接，供应商关闭的连接也会立即重连，不必等到有声音。
  - 供应商无法连接或响应很慢时会拖住其他一切：重试期间停止或退出最长要等一分钟，音频也会丢失。现在连接在后台进行，每个网络步骤都有时间上限。
  - 错误提示现在会显示具体原因（例如 `connection timed out`），识别恢复后连接错误会自动消失，面板也会标出正在重连的一侧。
  - 供应商不接受的设置现在报告为 `MC-ASR-004`，而不是网络问题（`MC-ASR-002`），也不会再每秒重试多次。
  - 在配置了 IPv6 但实际不通的网络上，连接不再超时。
- 面板上的电平条在会话开始前一直不动，麦克风在 **设置 › 音频** 里正常，在面板上却像没有声音。现在面板显示时，按下 **开始** 之前也会显示两侧电平；在你按下开始之前不会向任何地方发送内容。
- 麦克风只传来静音（被 Windows 隐私设置禁止或已静音）时，现在会提示 `MC-AUD-002`。
- MeetCue 内部的意外错误现在会写入日志。

## 0.1.3 — 2026-10-24

### 变更

- 价格直接读取自 Anthropic、Soniox、Deepgram 的官网价格页，以及在模型列表中附带价格的 OpenAI 兼容接口。现在每个当前的 Claude 模型都显示价格和预计费用；只有在任何来源都没有价格的模型才链接到价格页。
- Deepgram 显示当前实际收费的费率（包括限时优惠），常规费率显示在提示中。
- 会议进行中更换模型、密钥、语言或提示设置会立即生效：下一个问题使用新模型，语音识别切换时也不会丢掉正在说的那句话。
- 所有设置都可以在程序中修改：人声检测门限和句末静音（现最长 3 秒）改为滑块；**通用** 中新增面板形态和 **重置面板位置**；可 **重新运行设置向导**；可修改全部费用估算假设；列出你填写的价格并可 **删除**；可编辑练习复盘统计的口头禅。更换麦克风或人声门限在会议中也会立即生效。

### 新增

- **设置 › 诊断 › 运行日志** 实时显示 MeetCue 在做什么：开始与暂停、两侧是否收到音频、识别出的句子、问题和错误。也可从托盘菜单和任意错误提示打开。

### 修复

- 缺少密钥、模型或音频设备时，点 **开始** 或 **继续** 没有任何反应；现在会显示原因，音频启动失败时也不会留下半开的会话。
- 快捷键被占用等提示之前从不显示。
- 暂停时会议计时仍在走。
- 设置页面较长时，左侧标签栏会被滚走。
- 语音识别：
  - 一句话的开头经常被截掉；现在会连同说话前 0.3 秒一起发送。
  - 连接第二次中断后，或暂停超过几秒后，本场会议的识别会彻底停止；现在暂停期间会保持连接，并在需要时自动重连。
  - 使用 Deepgram 时，英文句子各段之间丢失空格（如 “yourexperience”）。
  - 使用 Deepgram 且同时选择中文和英文时，英文会被送进普通话模型。现在 **会议语言** 中的第一个语言为主要语言，并新增“以英文为主，夹杂中文”选项。
  - 句末静音设置被截短为 0.8 秒。

## 0.1.2 — 2026-10-24

### 变更

- 价格不再内置在程序中。MeetCue 会下载对照各供应商官网核对过的[价格参考](/zh/reference/pricing)，保留最近一份供离线使用，并可在 **设置 › 供应商与费用** 中更新。
- 更紧凑的 **模型与价格** 布局：每个模型一行，显示单价和预计每小时费用，按费用排序，并标出 **最省** 和 **最快**。API 密钥每个供应商一行。
- 没有公开价格的模型改为链接到供应商官网价格页，不再显示 **价格未知**。

### 修复

- Deepgram Nova-3 之前按多语言费率计算。MeetCue 识别中文或英文时只请求单一语言，费用为每分钟 0.0077 美元。

### 新增

- Claude Sonnet 5、Claude Opus 5 和 Claude Fable 5.1 的价格。

## 0.1.1 — 2026-10-24

### 修复

- Deepgram、Anthropic 和 OpenAI 兼容接口的密钥验证失败，使用它们的会话也无法开始：此前只接入了 Soniox。
- 在设置向导中点 **完成** 后，窗口变成空白而不是关闭。
- 设置中的开关滑块位置偏移。

### 移除

- Amazon Bedrock。要点生成请使用 Anthropic 或 OpenAI 兼容接口。

## 0.1.0 — 2026-10-23

### 新增

- 会议模式：实时问题检测与提前触发，约一秒半内给出编号要点，问题队列，已讲要点打勾。
- 不抢焦点的悬浮面板，支持完整与迷你两种形态、鼠标穿透和共享屏幕时隐藏。
- 语音识别支持 Soniox 和 Deepgram；要点生成支持 Anthropic、Amazon Bedrock 和 OpenAI 兼容接口。
- 延迟探测：自动选择端点、估算费用并对组合排序。
- 价格表、用量统计、预算提醒和 CSV 导出。
- 练习模式：导入字幕和问题列表并在预览中编辑，用系统语音朗读问题，支持真实识别和模拟延迟、追问、四档提示难度，以及可导出为 Markdown 的复盘报告。
- 支持 txt、md、docx 和 pdf 格式的会前资料。
- 中英双语界面与文档。
- 带解决办法链接的错误码、诊断信息导出、`--demo` 与 `--self-test`。
