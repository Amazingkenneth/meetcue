# 首次设置

本页介绍第一次启动 MeetCue 时打开的设置向导。整个过程约五分钟，大部分时间花在创建 API 密钥上。

## 开始之前

你需要一个语音识别供应商账号和一个大模型供应商账号。MeetCue 不替你选：每项任务的供应商和模型名都由你自己选择和填写。

| 任务 | 本版本支持的供应商 |
| --- | --- |
| 语音识别 | Soniox、Deepgram |
| 问题检测与要点生成 | Anthropic、任意 OpenAI 兼容接口 |

问题检测和要点生成可以用不同的模型，甚至不同的供应商。检测只需判断“是不是问题”，通常选便宜的模型就够了。

## 第 1 步：语言

选择 **English** 或 **简体中文**，也可以跟随 Windows 显示语言。之后可在 **设置 › 通用** 中修改，所有窗口即时切换。

## 第 2 步：音频

MeetCue 同时听两路声音：

- **麦克风（我）**：你说话用的麦克风。“系统默认”跟随 Windows 声音设置里选的设备。
- **与会者声音**：默认播放设备里播放的所有声音，会议软件就是从这里播放其他人的声音。

点击 **测试电平**，播放一段视频并说几句话，两个电平条都应跳动。如果系统声音一直没有电平，请看[音频与设备](/zh/troubleshooting/audio)。

::: tip 建议戴耳机
使用外放时，麦克风也会录到与会者的声音。MeetCue 能过滤大部分回声，但戴耳机效果最好。
:::

## 第 3 步：供应商与模型

为三项任务各选一个 **供应商**，并填写 **模型** 名。供应商接受的任何模型名都可以，包括本版本 MeetCue 发布之后才推出的模型；保存该供应商的密钥后，输入时会显示它返回的模型名作为建议。三项任务都选好供应商并填好模型后才能继续。

MeetCue 不列出模型和价格。每个供应商旁都有 **查看官网价格** 链接，指向其官方价格页；OpenAI 兼容接口请查看你所用服务的价格页。

任务下方的 **接口地址与密钥** 为每个选中的供应商显示一行：

- **接口地址**：OpenAI 兼容接口必填，例如 `https://llm.example.com/v1`。Anthropic 可选：留空则使用 `https://api.anthropic.com`，也可以填写兼容同一接口的网关或代理。
- **密钥**：粘贴后点击 **保存并验证**。密钥只保存在 Windows 凭据管理器中，不会出现在配置文件或日志里。

各家密钥的获取方法见[供应商配置](/zh/guide/providers)：

- [Soniox](/zh/guide/providers#soniox)
- [Deepgram](/zh/guide/providers#deepgram)
- [Anthropic](/zh/guide/providers#anthropic)
- [OpenAI 兼容接口](/zh/guide/providers#openai-compatible-apis)

验证失败时，提示里会带错误码，例如 [MC-ASR-001](/zh/troubleshooting/error-codes#mc-asr-001)。点击 **查看解决办法** 可直接打开对应说明。

## 第 4 步：延迟探测

探测会测量从你的网络访问各供应商的速度，并为每家选出最快的端点。有密钥时花费几美分；只测网络则完全免费。可以先跳过，之后在 **设置 › 供应商与费用** 中运行。参见[延迟探测](/zh/guide/latency)。

## 第 5 步：完成

下次会议开始时按 `Ctrl+Alt+Space`。想先看看效果，可以试试[五分钟上手](/zh/quick-start)。

想在真实会议前用自己的声音把整个流程试一遍，点 **完成并开始模拟面试**。见[模拟面试](/zh/guide/mock-interview)。
