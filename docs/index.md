## Install in one minute

MeetCue for Windows installs with [Scoop](https://scoop.sh), without administrator rights:

```powershell
scoop bucket add meetcue https://github.com/Amazingkenneth/meetcue
scoop install meetcue
```

Then follow [first-time setup](/setup).
