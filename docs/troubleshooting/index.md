# Troubleshooting

Start from what you see. Each entry links to the page that explains causes, checks and fixes.

## Error messages

Every MeetCue error shows a code like `MC-AUD-001`. Click **See the fix** in the message, or look the code up in [Error codes](/troubleshooting/error-codes).

## Ask for help

1. [Export diagnostics](/troubleshooting/diagnostics). The file contains no API keys, transcripts or briefing material.
2. [Open an issue](https://github.com/Amazingkenneth/meetcue/issues/new?template=bug.yml) with the error code, your MeetCue version and the steps that lead to the problem, and attach the diagnostics file.
