Error codes ​

Every message in MeetCue shows a code such as MC-AUD-001. Find the code below for what it means and how to fix it. The See the fix button in the app opens this page at the right code.

Audio ​

MC-AUD-001 ​

The audio device is in exclusive use · Error

How to fix: In Sound settings, open the device's properties, and on the Advanced tab clear "Allow applications to take exclusive control of this device".

MC-AUD-002 ​

The microphone is blocked or muted · Error

How to fix: Turn on microphone access for desktop apps in the system privacy settings and check that the microphone isn't muted (mute key, headset switch or Sound settings), then restart capture.

MC-AUD-003 ​

No usable audio device was found · Error

How to fix: Connect a microphone or speakers, make sure they are enabled in Sound settings, then pick them again in Settings › Audio.

MC-AUD-004 ​

The audio device changed; capture restarted · Notice

How to fix: Nothing to do. If the level bars stay flat, pick the device again in Settings › Audio.

MC-AUD-005 ​

System sound capture receives only silence · Warning

How to fix: Check that the meeting plays through the default output device. Mute your speakers or use headphones while testing so the microphone does not pick up the sound instead.

MC-AUD-900 ​

Audio capture is not available on this platform yet · Error

How to fix: This build supports audio capture on Windows only. Practice mode with speech-to-text for the questions turned off still works.

Speech recognition ​

MC-ASR-001 ​

The speech recognition API key was rejected · Error

How to fix: Copy the key again from the provider console, paste it in Settings › Providers, and select Verify.

MC-ASR-002 ​

Could not connect to the speech recognition service · Error

How to fix: Check your network or proxy, then run the latency probe to pick a reachable endpoint.

MC-ASR-003 ​

The speech recognition service is limiting requests · Warning

How to fix: Wait a minute and try again. If it keeps happening, check the quota and balance in the provider console.

MC-ASR-004 ​

The speech recognition service returned an unexpected response · Error

How to fix: Update MeetCue to the latest version. If the problem persists, export diagnostics and open an issue.

MC-ASR-005 ​

No speech recognition provider is set up · Error

How to fix: Choose a provider and enter its API key in Settings › Providers, or start demo mode to try MeetCue without keys.

Language models ​

MC-LLM-001 ​

Hint generation timed out · Warning

How to fix: Run the latency probe and switch to a faster model or endpoint. Hints for the next question are generated as usual.

MC-LLM-002 ​

The language model API key was rejected · Error

How to fix: Copy the key again from the provider console, paste it in Settings › Providers, and select Verify.

MC-LLM-003 ​

The language model service is limiting requests · Warning

How to fix: MeetCue retries automatically. If it keeps happening, check the rate limits and balance of your account.

MC-LLM-004 ​

The selected model is not available · Error

How to fix: Pick another model in Settings › Providers.

MC-LLM-005 ​

The language model request failed · Error

How to fix: Check your network and the provider status page, then try again.

MC-LLM-006 ​

The model's answer could not be read · Warning

How to fix: Usually a one-off. If it happens often, choose a more capable model for hint generation.

Shortcuts ​

MC-HK-001 ​

A shortcut is already used by another program · Warning

How to fix: Open Settings › Shortcuts and assign a different key combination to the item marked in red.

System ​

MC-SYS-001 ​

The WebView2 runtime is missing · Error

How to fix: Install the Evergreen WebView2 Runtime from Microsoft, then start MeetCue again.

MC-SYS-002 ​

The settings folder is not writable · Warning

How to fix: MeetCue saved settings to your user profile instead. Check the folder permissions if you want portable settings.

MC-SYS-003 ​

The system credential store is unavailable · Error

How to fix: API keys are kept only in the system credential store. Make sure it is running (Credential Manager, Keychain or Secret Service) and try again.

MC-SYS-004 ​

This feature is not supported on this platform yet · Notice

How to fix: The feature is planned for a later release. See the platform support table in the docs.

Network ​

MC-NET-001 ​

A secure connection could not be established · Error

How to fix: If your network uses an HTTPS proxy, set the proxy address in Settings › Providers › Advanced and make sure its certificate is trusted by the system.

Budget ​

MC-BUD-001 ​

80% of the budget is used · Warning

How to fix: Spending is close to the limit you set. Adjust the budget in Settings › Providers if needed.

MC-BUD-002 ​

The budget is used up · Warning

How to fix: MeetCue applied the action you chose for this case. Raise the budget in Settings › Providers to continue.

Practice ​

MC-PRC-001 ​

The practice file could not be read · Error

How to fix: Use an .srt, .vtt, .txt, .md or .csv file. See the file format reference for examples.

MC-PRC-002 ​

Speech synthesis is not available · Warning

How to fix: Install a text-to-speech voice for the question language in the system settings, or practice with on-screen questions only.

Diagnostics ​

MC-DIAG-001 ​

Diagnostics could not be exported · Error

How to fix: Pick a folder you can write to, for example Documents, and try again.

Still stuck? Export diagnostics and open an issue with the code.
